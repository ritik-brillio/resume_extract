System Architecture & Technical Pipeline

Hybrid retrieval topology, execution sequence & rubric calibration

Stage 1: Document Conversion & Normalization

Uploaded documents (.pdf, .docx, .txt) are converted to deterministic GitHub-flavored markdown via MarkItDown. Sections (Experience, Skills, Projects) are cleanly extracted.

Stage 2: Priority Weighting & Clause Splitting

Job description clauses are parsed alongside Must-Have and Good-to-Have input tags. Must-Have requirements receive a 3.0 weight multiplier; Good-to-Have receive 1.0.

Stage 3: Hybrid Lexical + Dense Semantic Scoring

Passages are evaluated using BM25 keyword matching and all-MiniLM-L6-v2 cosine distance. The ATS sigmoidal curve maps raw matches ≥50% to 75–85% to eliminate score depression.

Stage 4: Recruiter Calibration & Scorecard Delivery

Applies Applied Project Justification (10%) and YoE Duration Fit (10%). Renders the candidate comparison table with the Overall Score placed at the extreme right.
